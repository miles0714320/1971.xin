这个网站最初是**一页手写 HTML**：3KB，11 个文件，一个页面说清楚"我是谁"。
够用，克制，我很喜欢。

但当我开始想往里面**持续放东西** —— 工具收藏、折腾记录 ——
手写 HTML 的维护成本立刻暴露：每加一篇东西，都要复制一整页、改导航、
改列表，页面之间没有任何东西是自动的。

## 为什么是 Astro

试过几个方案之后选了 Astro，理由很实际：

- **内容是 Markdown**：一篇文章就是一个 `.md` 文件，写完扔进文件夹就行
- **纯静态输出**：没有任何后端，托管成本依然是零
- **不发 JS 到浏览器**：默认零客户端脚本，页面快得像十年前的网站

## 迁移过程

结构很简单：`tools` 和 `articles` 两个内容集合，
首页取"精选工具 + 最新文章"自动拼出来。

原来那套部署管道**一行没改**：还是 git push →
GitHub Actions → Cloudflare Pages。只是 Actions 里多了一步构建。

## 旧版去哪了

git 历史里。想回去随时能回去 —— 这也是把网站放在 git 里最大的好处：
**任何"升级"都是可逆的**。
